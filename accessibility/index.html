Public commitment

Learning should not depend on navigating avoidable barriers.

ARCTURA aims to make its public website and learning materials usable across different devices, input methods, visual needs, and motion preferences. Accessibility is a continuing engineering and editorial responsibility.

Target

WCAG 2.2 Level AA.

This is a conformance target, not a current third-party certification. Automated structural checks are active; broader assistive-technology and user testing remain ongoing work.

Current implementation

Accessibility is built into the shared shell.

Keyboard and structure

Pages provide a skip link, one primary heading, landmark regions, descriptive link text, visible focus, and keyboard-operable navigation.

Navigate without a pointer

Responsive reading

Layouts reflow from wide screens to small devices without requiring a separate mobile site. Tables may scroll horizontally rather than truncate content.

Content survives the viewport

Motion and images

Reduced-motion preferences disable nonessential transitions. Content images have descriptive alt text and essential meaning remains in HTML.

Decoration is not instruction

Known limits

Testing is meaningful only when its boundary is stated.

The current release has automated checks for headings, landmarks, metadata, alt text, link targets, intrinsic image dimensions, and shared navigation structure. It has not yet completed independent WCAG conformance evaluation or a documented test matrix across screen readers, magnification, voice input, high-contrast modes, and multiple browser/operating-system combinations.

Generated editorial artwork may contain fine visual detail that is not essential to completing a lesson. Interactive browser tools rely on native form controls and produce plain-text Markdown, but they still require broader assistive-technology testing.

Feedback

Report the barrier with enough context to reproduce it.

Open a public issue with the page URL, task you were trying to complete, browser or assistive technology when relevant, what happened, and the outcome you expected. Do not include private or sensitive information.

If a public issue is not appropriate, email learn@arctura.org. Availability and response time are not yet guaranteed; material barriers will be tracked in the repository when disclosure is safe.

Alternative access: if a learning artifact is unusable in its current presentation, request a plain-text or structurally simplified version and identify the affected route.

Reference

Use the current shared standard.

The conformance target is informed by the W3C Web Content Accessibility Guidelines WCAG 2.2. The standard does not endorse ARCTURA, and linking it does not establish conformance.
