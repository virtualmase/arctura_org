Arctura Protocol

Payment moves. Verification travels.

Arctura Protocol is an early-stage documentation surface for a proposed verification bridge between Lightning payment proofs and EVM-facing agent infrastructure. The intent is narrow: let downstream systems confirm that a payment cleared without each system operating its own Lightning node.

Current state

Early-stage infrastructure.

The current public draft describes a single verified test transaction, a contract on Base mainnet, an incomplete audit state, and SDK/MCP work in development. Treat the system as building, not production-ready.

Security and scope notice: This page is a technical status and design surface. It does not provide investment advice, payment guarantees, custody, automated trading, or a representation that the protocol has completed an independent security review.

Verification flow

From payment proof to downstream confirmation.

The proposed system creates a bounded verification event. It does not make the agent the owner of a payment rail, and it does not remove the need for threat modeling, source publication, and independent review.

Lightning payment

A payer or agent completes a Lightning payment through its chosen payment rail.

Proof submission

A payment proof is submitted to the verification contract through the documented interface.

On-chain check

The contract checks the submitted proof according to the published protocol rules and emits a result.

Bounded action

A downstream system can use the confirmation event under its own policy, approval, and failure-handling rules.
