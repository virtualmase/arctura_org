Operating posture

Useful work leaves
a visible trail.

Start with the record.

Keep sources, assumptions, and changes close enough to the work that others can inspect them.

State the boundary.

Separate a source note, a concept, a prototype, and a live service before the language outruns the evidence.

Make it usable.

Translate a position into a small tool, a portable artifact, or a route another person can actually take.

Keep it reviewable.

Prefer work that can be challenged, revised, and carried forward without a single point of authority.
